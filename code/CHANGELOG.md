# CHANGELOG

## [Unreleased] - 2026-03-07

### 🚀 新特性 (Features)
- **嫌疑人心理状态机非线性进化**: 在 `psych_state.py` 中引入了非线性的心理防线扣减与压力增加模型。实现了基于“确凿证据”的暴击伤害（1.5倍基础），以及面对“诈供陷阱”被识破后的防线反弹机制，提升了心理模拟的真实度。
- **高压状态下的“记忆模糊化”**: 在 `event_kg_module.py` 中实现。当嫌疑人压力值超过 80 时，其回忆的具体细节（金额、日期）会被模糊化处理，模拟嫌疑人高压下的记忆混乱错觉。
- **欺诈算子精准定点注入**: 优化了图谱抽取逻辑，现在只有在审讯问题命中了特定的嫌疑事实节点时，才会将对应的 `fallback_strategy` 指令注入系统提示词，有效避免了长篇无关策略导致的指令污染。
- **历史口供自洽审查**: 在 `generator.py` 中增加了强制要求，将嫌疑人近期回答的回顾作为强约束输入，迫使其接下来的狡辩或谎言必须在逻辑上“圆上”之前的说辞。
- **性格反应模式条件触发**: 将 `personality.py` 中的战术反应模式重构为字典，引入了 `max_stress` 元数据过滤器，不同性格现在只有在符合自身压力特征的前提下才会触发相应的战术动作（例如压力不到100就不可能崩溃）。
- **动态回复字数控制 (Verbosity Rules)**: 各个性格类现实现了 `get_verbosity_rules` 接口，废除了全剧唯一的 400 字硬编码，转而根据不同的性格流派和压力值给出差异极大的长度指示（例如沉默型仅准说几句话，而圆滑伪装型在面临压力时会大幅拉长发言转移焦点）。

### ⚖️ 平衡性调整 (Game Balance)
- **大幅拉长博弈回合数**: `psych_state.py` 中的防御扣减基准由总量的 `10%` 下调至 `4% - 5%`，并将暴击乘数由 `2.5倍` 削减至 `1.5倍`。现在，面对纯粹的强压和出示死证，心理防线70以上的嫌疑人也需要至少 10-15回合以上才能被击破，极大延伸了谈判拉扯的可玩时间。
- **调整全局回复文本长度上限**: 增加了对话大模型的内部最大思考、生成 Token 限制，并配合严格的最终输出长度约束，使得心路历程能够思考更深，但对外的台词保持相对克制精炼。

### 🐛 缺陷修复 (Bug Fixes)
- **修复 UI 漏报率和逻辑评分停止更新**: 修复了 LangGraph 更新至 Streamlit 的状态传播问题，同时完善了裁判模块对于嫌疑人相关特化字段的生成（03-04）。
- **表单布局与请求挂起修复**: 修复了页面中人物资料表单没有占满全宽以及“保存加载”卡死、API请求集成不通顺的问题（03-05）。

---## [Unreleased] - 2026-03-01

### 🚀 新特性 (Features)
- **性格引擎面向对象重构 (Strategy Pattern)**: 彻底移除了原先基于 Enum 和巨大硬编码配置字典的性格处理方式。引入了 `personality.py`，通过基类 `BasePersonality` 派生出 `ArrogantPersonality`、`NervousPersonality` 等。现在各种性格能通过多态形式自行计算抗压系数和谎言倾向，极大提升了系统的可扩展性。
- **LangGraph Web 深度整合**: 彻底重构了 `app.py` 的执行循环，移除了硬编码的代理调用循环。现在 Streamlit UI 通过原生的 `StateGraph` 与 `workflow.py` 通信，并利用 `interrupt_after` 实现了正统的断点回合制交互，彻底杜绝了并发下的全局变量污染。
- **全局日志规范化**: 引入了 `loguru`，彻底替换了之前零散的标准 `logging` 注入。配置了带颜色的 Console 输出和统一存放至 `/logs` 每日切分文件。
- **审讯报告自动导出**: 新增 `export_utils.py`，现在在任意模拟局以胜利或失败结束后，系统会自动将对抗全过程生成 Markdown 审讯纪要存入 `saved_reports/`，含逻辑失分与泄露率等评估。
- **Prompt 热插拔化**: 将原本散落在 `generator.py`、`interrogator.py` 与 `referee.py` 中的硬编码 Python f-string 提取到了 `prompts/` 文件夹下，并编写了 `prompts.py` 动态读取器。

### 🐛 缺陷修复 (Bug Fixes)
- **修正 `referee.py` 返回格式异常**: 修复了裁判模块最后产生评估时抛出的 `AttributeError` 崩溃。将原先直接返回 Markdown 字符串的方法改写为返回结构化 Dict，由调用端（Streamlit 和导出脚手架）负责格式化。
- **修复嫌疑人“金鱼记忆”问题**: 修正了 `event_kg_module.py` 中历史供词的上下文注入长度，将其从全量加载约束至仅近期 5 回合，有效防止了 LLM 因为 Context 过载而产生的初期设定遗忘与幻觉。
- **修复“Truth Decay”与过度抵抗**: 更新了嫌疑人的 System Prompt，新增了**“有限承认原准 (Limited Admission)”**。强制要求嫌疑人在面对确凿证据（如 DNA、照片）时必须承认客观事实存在，但必须从动机方向狡辩，禁止再次发生白痴式的过度否认。
- **修正 `referee.py` 属性报错**: 修复了游戏结束结算时，裁判类企图读取心理状态机错误的 `defense_value` 的 Bug，统一矫正为 `defense`。
- **修复 `workflow.py` 拼写与导入遗留错误**: 全面将其从 `Langgrah.py` 更名为标准的 `workflow.py`，并在后续重构性格模块时修正了遗留导入 `PersonalityType` 的 `NameError`。

### 📦 基础工程构建 (Chores & Infrastructure)
- **Poetry 上线**: 全面弃用粗糙的 requirements 管理，引入了 `pyproject.toml` 作为包与虚拟环境的主要管理方案。
- **单元测试解绑**: 引入了 pytest 作为默认的测试脚手架，在 `tests/` 目录下建立了初步的依赖隔离。
- **脱敏与开源规范化**: 引入 `.env` 并增加 `.env.example`，将阿里云或 OpenAI 的 Key 等敏感配置抽离代码仓库，并在 `.gitignore` 中正确配置了反向隔离。
